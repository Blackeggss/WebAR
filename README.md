# WebAR

ブラウザだけで動く顔認識ARカメラアプリです。ビルド不要の静的サイトとして構成されており、Webカメラの映像に対してリアルタイムで顔の位置・向きを検出し、3Dのマスク(仮面)を重ねて表示・撮影できます。

## 主な機能

- **リアルタイム顔トラッキング**: [MediaPipe Tasks Vision (FaceLandmarker)](https://developers.google.com/mediapipe/solutions/vision/face_landmarker) を用いて顔のランドマークを検出し、[Three.js](https://threejs.org/) で3Dマスクを顔の位置・回転に追従させて描画します。
- **ARマスクの切り替え**: 画面下部のスイッチャーをドラッグ操作でめくりながら、複数のマスクを切り替えられます。
- **マスクのアップロード**: 正方形・半透明のPNG画像を自分でアップロードして、オリジナルのARマスクとして追加できます。
- **写真撮影・ギャラリー**: シャッターボタンで撮影し、アプリ内蔵のギャラリーで撮影した写真の閲覧・保存・削除ができます。
- **カメラ切り替え**: フロント/リアカメラの切り替えに対応(PCでは接続されているカメラを選択するUIも用意)。
- **端末モーション対応**: iOS Safari など許可が必要な端末向けに、モーション/向きセンサーの利用許可をリクエストするオーバーレイを表示します。

## 動作環境

- カメラ(`getUserMedia`)を使用するため、**HTTPS** または **localhost** でのアクセスが必要です(HTTP経由では動作しません)。
- 最新の Chrome / Safari など、ES Modules・WebGL・WebAssembly に対応したモダンブラウザを推奨します。

## 技術スタック

- [Three.js](https://threejs.org/)(`importmap` 経由でCDNから読み込み)
- [MediaPipe Tasks Vision](https://developers.google.com/mediapipe/solutions/vision/face_landmarker)(CDNから読み込み)
- Vanilla JavaScript (ES Modules) / CSS / HTML — フレームワークやビルドツールは使用していません

## セットアップ・起動方法

ビルド処理は不要です。任意の静的ファイルサーバーでホストしてください。

```bash
# 例: Pythonの簡易サーバーを使う場合
python3 -m http.server 8000
```

```bash
# 例: Node.jsのserveパッケージを使う場合
npx serve .
```

起動後、ブラウザで `http://localhost:8000` などにアクセスしてください。スマートフォンなど別端末から確認する場合は、HTTPS経由でアクセスできるようにするか、`localhost` として扱われる方法(トンネリングサービスなど)を利用してください。

## 使い方

1. ページにアクセスするとカメラへのアクセス許可を求められるので許可してください。
2. 一部端末では画面をタップしてモーションセンサーの利用許可も行ってください。
3. 顔が検出されると、選択中のARマスクが顔に追従して表示されます。
4. 画面下部のスイッチャーをドラッグして、マスクを切り替えられます(「+」からオリジナル画像のアップロードも可能)。
5. シャッターボタンで撮影し、ギャラリーボタンから撮影した写真の閲覧・保存・削除ができます。
6. カメラ切り替えボタンでフロント/リアカメラを切り替えられます。
